========================================================================
APEX LEAGUE HUB - SPORTS LEAGUE MANAGEMENT SYSTEM
Standalone Portable Static Web Application
========================================================================

HOW TO RUN:
1. Double-click "index.html" to open the application in any web browser (Chrome, Edge, Firefox, Safari).
2. No Node.js, npm, Vite, or web server installation is required.

PROJECT STRUCTURE:
sports-league-saas/
│
├── index.html       - Main HTML application shell
├── style.css        - Complete dark-mode glassmorphism design system
├── script.js       - Interactive application logic, routing, and Chart.js integration
├── data.js         - Initial mock data store for teams, players, matches, venues & standings
├── assets/
│   ├── images/      - Stadium hero graphics & venue photos
│   ├── icons/       - Icon asset directory
│   └── fonts/       - Font asset directory
└── README.txt       - Overview and usage documentation

FEATURES:
- Landing Page with hero stadium overlay & feature cards
- Glassmorphism Login Page with role selector
- SaaS Executive Dashboard with 7 KPI stats cards & interactive charts
- Teams Management View (Cards, roster links, stats, edit/delete)
- Players Directory View (Searchable table with Team & Position filters)
- Coaches View (Profile cards with credentials)
- Matches View (Fixtures, live score badges, result updates)
- Tournament View (Knockout Bracket visualizer, Group stage table)
- Venues View (Stadium photos, capacity, location)
- Referees View (Rating stars, experience badges)
- League Standings (Points table with UEFA/Relegation highlights)
- Reports & Analytics (Multi-chart performance reporting)
- Dynamic Modals for Add Team, Add Player, Schedule Match, Update Score
